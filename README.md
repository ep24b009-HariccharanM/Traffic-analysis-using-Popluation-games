# Traffic-analysis-using-Popluation-games
This project aims to analyze traffic in a simulated road system using Population games and evolutionary dynamics.

In the Flaw finder code, the program calculates the equilibrium time for given road system. Then the program removes the road links one by one and checks the road link that can minimize the total travel time. Then the code removes the road link and repeats the process till it reaches a system of links where the removal of any link can only increase the time taken to travel.

I have chosen an arbitrary road system where all the travels move from the same starting point to ending point. The final road system is much simpler than I expected it to be.
